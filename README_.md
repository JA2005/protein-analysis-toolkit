# 🧬 Protein Analysis Toolkit (R)

A simple R toolkit for basic protein sequence analysis — perfect for beginners and teaching demos.

## 🚀 Features
- Read protein FASTA files
- Get amino acid composition (%)
- Calculate molecular weight
- Estimate isoelectric point (pI)

## 💻 How to use
1. Download or clone this repo:
   ```bash
   git clone https://github.com/<YOUR_USERNAME>/protein-analysis-toolkit.git
   cd protein-analysis-toolkit

# Open R and run
